# utils-plugin

Utility tools: code quality, external research, codebase exploration, session analysis.

## Structure

- `skills/` - 6 skills (deslop, research-agent, rp-explorer, figma-to-code, ui-verify, plugin-release)
- `agents/` - 1 agent (braintrust-analyst)
- `scripts/` - 4 scripts (perplexity_search, braintrust_analyze, firecrawl_scrape, nia_docs)
- `commands/` - 1 command (deslop)
